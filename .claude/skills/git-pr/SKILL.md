# git-pr

사용자가 요청할 때만 수행.

1. 기본 브랜치면 중단하고 보고.
2. 미커밋 변경이 있으면 `/git-commit` 먼저 수행.
3. `/code-review` 실행. 지적 사항은 사용자에게 보고.
4. 브랜치 푸시 후 `gh pr create`로 생성. 대상은 기본 브랜치.
    - 제목: 커밋 형식(`<type>: <요약>`), 70자 이내.
    - 본문: `## 요약`, `## 변경`, `## 검증`.
    - 하드웨어 프로필, 보정값 변경이 있으면 `## 하드웨어 영향` 추가.
5. PR 링크 보고.

본문은 단순 종결형. 금지 사항은 `@.claude/rules/git.md`. 검증에는 `/klipper-sim` 결과를 기재.

# 문서 스타일

- 어투는 단순 종결형("~함", "~수행", "~실행").
- 군더더기, 불필요한 설명 금지.
- 같은 내용은 한 곳에만 둠. 다른 곳은 참조.
- 주석은 이유가 불분명할 때만 작성.

## 서식

- 문서는 한 줄 표시 폭 100칸 이내. 한글은 2칸.
- 코드(py, sh, cfg)는 한 줄 표시 폭 120칸 이내.
- frontmatter의 description도 같은 기준. 길면 `>-`로 줄을 나눔.
- 긴 문장은 문장 단위로 나눠 하위 목록으로 씀.
- 제목, 목록 앞뒤에 빈 줄.
- 중첩 목록은 4칸 들여쓰기.
- 표는 열 4개 이하, 셀은 짧게. 길면 목록으로 씀.
- 표 열 정렬은 IDE 포매터(글자 수 기준)를 따름.
- 줄 끝 공백 금지. 파일 끝 개행 1개.

# 문제 해결

증상별 조치, 청소, 정기 점검.

## 증상

먼저 Mainsail 콘솔 메시지와 `klippy.log` 마지막 오류 확인.

- Vref 조정은 `@docs/first-power.md`, 보정 공식은 `@docs/calibration.md`.

### 연결, 구동

- mcu에 연결되지 않음
    - 확인: `ls /dev/serial/by-id/`에 줄이 있는지. USB 칩 이름은 `@hardware/active/NOTES.md`.
    - 조치: 없으면 `lsusb`, `dmesg`로 인식 확인.
    - 조치: OTG 젠더가 Pi 데이터 단자인지, 데이터용 A–B 케이블인지 확인.
    - 조치: 있으면 `@hardware/active/printer.cfg` `[mcu] serial`을 `ls` 결과와 같게 고침.
- `make flash` 실패
    - 확인: Klipper 서비스가 멈췄는지.
    - 조치: `sudo service klipper stop` 후 재시도. `FLASH_DEVICE` 경로 확인.
    - 조치: 보드 리셋 버튼 직후 재시도.
- Klipper가 시작 안 됨
    - 확인: `klippy.log` 마지막 줄.
    - 조치: 섹션 이름, 핀 이름 오타 수정.
- Mainsail이 느리거나 끊김
    - 확인: Pi 저전압 경고, Wi-Fi 신호.
    - 조치: 강압 모듈 출력 전압 확인. 공유기를 가까이 둠.

### 모터, 드라이버

- 모터가 떨기만 하고 안 돎
    - 확인: 코일 쌍, Vref.
    - 조치: 멀티미터로 코일 쌍 재확인(1-2, 3-4). Vref 0.05 V씩 올림.
- 모터에서 높은 소리가 계속 남
    - 확인: 코일 쌍, 마이크로스텝 점퍼.
    - 조치: 코일 쌍 재확인. 점퍼와 `[stepper_*] microsteps` 일치 확인.
- 드라이버가 뜨겁거나 중간에 멈춤(과전류 보호)
    - 확인: Vref, 방열판, 박스 팬.
    - 조치: Vref 0.05 V씩 낮춤. 방열판, `[controller_fan box]` 확인.
    - 조치: 멈췄으면 전원을 껐다 켬.
- 축이 걸음을 잃음, 힘이 모자람
    - 확인: Vref, 기구 걸림.
    - 조치: 손으로 움직여 걸림 확인. 없으면 Vref 0.05 V씩 올림.
- 드라이버가 갑자기 죽음
    - 확인: 24V 켠 채 모터 커넥터를 만졌는지.
    - 조치: 드라이버 교체(`@docs/first-power.md` 드라이버 주의).

### 원점, 기구

- `G28`에서 Z 스위치를 못 찾음
    - 확인: `QUERY_ENDSTOPS`, 레버 끝 높이.
    - 조치: 레버 끝이 빔 윗면 바로 위에 오게 굽힘.
    - 조치: 꽂은 단자와 `[stepper_z] endstop_pin` 일치 확인.
- 갠트리가 오르내리며 기울어짐
    - 확인: 한쪽 커플러 풀림, 한쪽 모터만 도는지.
    - 조치: 커플러 조임, 스크루 베어링 재정렬, 빔 수평(`@docs/calibration.md`).
    - 조치: 뒤 휠을 너무 세게 밀었으면 한쪽이 더딤.
- 주사기가 클립에서 안 빠짐, 헐거움
    - 확인: 클립 크기, 날개가 받침 위인지.
    - 조치: 클립을 한 치수 바꿈. 받침 높이 재조정.

### 글씨, 크림

- 글씨가 도중에 앞뒤로 밀림
    - 확인: Y 벨트 장력, Y 풀리 세트 스크류.
    - 조치: 조임.
    - 조치: 큰 케이크에서만 생기면 `@hardware/active/cream_vars.cfg` `variable_print_accel` 낮춤.
- 글씨 가장자리가 물결침
    - 확인: 헤드 기둥, 캐리지 판 볼트, 벨트 장력.
    - 조치: 볼트 조임. `[input_shaper]`가 있으면 값을 낮추거나 지움.
- 줄이 끊기거나 가늘어짐
    - 확인: 크림 속 공기, 짤주머니 꼬임, 깍지 막힘.
    - 조치: 채울 때 톡톡 침. Extrusion factor 올림. 크림을 더 단단하게.
- 획 시작, 끝에 뭉침
    - 확인: 크림이 늦게 나오고 늦게 멈추는지.
    - 조치: `pressure_advance` 조정(`@docs/calibration.md`).
- 크림이 처지고 물러짐
    - 확인: 카트리지를 밖에 둔 시간, 방 온도.
    - 조치: 꺼낸 카트리지는 10분 안에 사용. 오븐, 햇빛에서 멀리.

### 피스톤

- 밀대가 닿기 전에 짜기 시작, 너무 눌러 튐
    - 확인: 카트리지마다 채운 양.
    - 조치: 같은 눈금까지 채움. 또는 `variable_load_mm` 조정(`@docs/calibration.md`).
- 피스톤 모터에서 딱딱 소리
    - 확인: 크림이 너무 단단, 차가움, 깍지 막힘.
    - 조치: 깍지 청소, 짜는 속도 낮춤. 피스톤 드라이버 Vref 0.05 V씩 올림.
- 쉬는 동안 밀대가 올라감
    - 확인: 모터가 꺼졌는지. 피스톤 로드는 스스로 잠기지 않음.
    - 조치: `@hardware/active/printer.cfg` `[idle_timeout] timeout` 확인.
    - 조치: PAUSE가 이보다 길면 모터가 꺼져 원점, 밀대 위치가 사라짐.
    - 조치: 취소 후 `G28`, 표시선 맞춤부터 다시.
- 밀대 원점이 어긋남
    - 확인: 작업을 중간에 멈췄는지.
    - 조치: `@docs/first-power.md` 절차 10의 표시선 맞춤.

## 청소, 위생

| 부품                       | 언제         | 방법                                             |
|----------------------------|--------------|--------------------------------------------------|
| 짤주머니                   | 채울 때마다  | 일회용, 버림                                     |
| 깍지, 커플러               | 하루 끝      | 따뜻한 물과 주방 세제, 깍지 솔                   |
| 주사기, 플런저             | 하루 끝      | 안팎을 알코올로 닦고 말림                        |
| 클립, 날개 받침, 헤드 아래 | 하루 끝      | 알코올로 닦음. 서미스터, 헤드 선에 물 주의       |
| 케이크 판, 컵              | 하루 끝      | 컵은 빼서 씻음. 판은 알코올                      |
| 기계 전체                  | 쓰지 않을 때 | 덮개를 씌움. 기름기, 밀가루가 레일에 쌓이지 않게 |

- 깍지, 커플러는 헹군 뒤 식품용 알코올 70 %로 마무리.

## 정기 점검

- 매주: X, Y 벨트 장력(주파수 앱), 벨트 가장자리 닳음.
- 매주: 작업 전 `G28`이 문제없이 끝나는지.
- 매달: V 휠 예압. 갠트리 끝을 비틀어 덜걱거림 확인.
- 매달: 리드스크루, 레일 블록 전부에 식품용 그리스.
- 매달: 빔 수평, 볼트 풀림(갠트리 판, 헤드 기둥, 풀리 세트 스크류).
- 매달: 케이블 체인, 늘어진 고리 꺾임. 전장 팬, 방열판 먼지.
- 6개월: 주사기 날개, 클립 금, 닳음(주사기는 소모품).
- 6개월: 휠 닳음, 체인 마디.
